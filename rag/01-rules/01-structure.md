# Определение формулы Осмакс

Формула — набор структурированных SLS-файлов, метаданных и при необходимости модулей, шаблонов и файлов, организованных в отдельной директории. Назначение: декларативное описание и автоматизация конфигурации системы (установка пакетов, настройка файлов, запуск сервисов).

## Как создаётся формула (JSON-first)

1. ИИ генерирует JSON по `11-json-spec-contract.md`.
2. `render_formula.sh` собирает дерево `<top_level_dir>-formula/` в `dist/`.
3. Человек проверяет по чеклистам `04-checklists/`.

ИИ **не** создаёт файлы формулы напрямую.

## Структура директорий

Формула — директория по шаблону:

```text
<top_level_dir>-formula/
```

Внутри обязательно есть поддиректория `<top_level_dir>`, имя которой совпадает с именем формулы.

Пример:

```text
my-script-formula/
  my-script/
    init.sls
    clean.sls
    map.jinja
    run.sls
    files/
  pillar.example
  FORMULA
  docs/
    README.RST
```

## Обязательные файлы

| Файл | Назначение |
|------|------------|
| `<top_level_dir>/init.sls` | Главный файл состояний apply; может включать другие `.sls` через `include` |
| `<top_level_dir>/clean.sls` | Откат состояний формулы |
| `pillar.example` | Пример параметров формулы |
| `FORMULA` | Описание формулы в YAML |

## Необязательные файлы

| Файл / директория | Назначение |
|-------------------|------------|
| `docs/README.RST` | Описание применения формулы и входящих состояний |
| `<top_level_dir>/any.sls` | Дополнительные состояния, включаемые в init/clean |
| `<top_level_dir>/any_dir/` | Поддиректории с `.sls`, включаемыми через `include` |
| `<top_level_dir>/map.jinja` | Особенности конфигурации под ОС и статические defaults |

### Дополнительно для `formula_kind=security-baseline`

| Файл / директория | Назначение |
|-------------------|------------|
| `<top_level_dir>/check.sls` | Compliance-check без исправления |
| `ssh/`, `sysctl/`, `services/`, `packages/` | Подсистемы политики (+ `.check`, `.clean`) |
| `files/` | Jinja-шаблоны (например sshd drop-in) |

## Правила именования SLS и директорий

Имена SLS-файлов и директорий:

- не могут содержать точки, кроме точки между именем и расширением `.sls`;
- могут включать латинские буквы, цифры `0-9`, `-` и `_`;
- соответствуют маске `[a-zA-z0-9-_]+`.

## Уникальность идентификаторов состояний

Каждому состоянию присваивается уникальный идентификатор в рамках продукта Осмакс.
