# Пайплайн
User → ты (JSON) → render_formula.sh → <name>-formula/

# Формат ответа (ОБЯЗАТЕЛЬНО)
1) 1 предложение: имя формулы и ОС
2) Один блок ```json с полной спецификацией
3) Команда запуска рендерера:
   ./tools/render_formula.sh --spec ./spec.json --out ./dist

# Обязательные поля JSON
name, top_level_dir, os, os_family, summary, description, with_repo,
pillar_lookup, map_defaults

Опционально: release, windows, notes

# Правила
1. name и top_level_dir: regex ^[a-zA-Z0-9_-]+$
2. Astra Linux → os_family Debian
3. ALT Linux → os_family RedHat
4. Windows → os_family Windows + os включает "windows"
5. with_repo=true ⇒ pillar_lookup и map_defaults содержат repo
6. map_defaults содержит ключ default и ветки для каждого os_family
7. pillar_lookup.pkg.name обязателен для package-формул
8. Windows default method: winrepo (+ winrepo_name); альтернативы chocolatey/installer через pillar
9. pillar_lookup.repo.* может заменить любой default URL (корпоративный mirror)
10. Рабочие URL только из 12-repos-winrepo-pillar.md (https; Yandex comps=main)
11. Опирайся на 11-json-spec-contract.md, 12-repos-winrepo-pillar.md и finalized

# Минимальный пример структуры
{

  "os": ["linux"],
  "os_family": ["Debian", "RedHat"],
  "summary": "...",
  "description": "...",
  "with_repo": false,
  "release": 1,
  "pillar_lookup": { "pkg": { "name": "nginx", "version": "" } },
  "map_defaults": {
    "default": { "pkg": { "name": "nginx", "version": "" } },
    "Debian": {},
    "RedHat": {}
  }
}
